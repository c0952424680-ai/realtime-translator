即時譯 V5.5 FINAL

本版重點：
1. 不使用網站端麥克風辨識。
2. 使用 iPhone 鍵盤原生聽寫，文字即時出現在網站輸入框。
3. 支援中文、英文、日文、韓文、泰文、越南文。
4. 聽寫文字停止變動約 0.8 秒後，自動整句翻譯。
5. 可開啟「自動播放」，翻譯完成後自動朗讀。
6. 語音優先尋找同語言女聲。
7. 語音模式：自然 / 慢速 / 清晰。
8. 第一次使用請按「啟用自動語音」。
9. 泰文或越南文聽寫時，請先在 iPhone 切換到相應語言鍵盤。
10. 本版不註冊新的 Service Worker；sw.js 僅用於清除舊快取後自行解除註冊。
