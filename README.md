# 即時譯 V10.4｜旅外安全助理・統一語音引擎版

V10.4 統一語音引擎：
- 翻譯與 SOS 共用單一 `voice-engine.js`
- 自動／女聲／男聲切換
- 語速慢／正常／稍快
- Safari `voiceschanged`
- 裝置實際 Voice 清單
- 可手動選擇 Voice
- 語音設定跨頁記憶
- 語言 locale 自動匹配
- 繁中 `zh-TW`、英文 `en-US/en-GB`、日文 `ja-JP`、韓文 `ko-KR` 等
- 找不到指定男／女聲時，自動 fallback 到同語言可用 Voice
- 翻譯內容與 TTS 播放邏輯分離
- SOS 人工校正求助句保留
