# 即時譯 V10.11

旅外安全助理 GPS 分離與 5 公里階梯搜尋正式修正版。

## 核心修正

- 手動旅遊國家／城市／行政區與裝置 GPS 座標完全分開保存。
- V10.9 舊定位只安全搬移國家與城市，不沿用可能偏移的舊經緯度。
- GPS 使用獨立時間戳，不再被其他狀態更新誤判為新定位。
- 附近搜尋依序使用 5、10、15、20、25、30、35、40 公里。
- 第一階段立即依直線 GPS 距離顯示；第二階段在背景計算道路距離並重排。
- 道路矩陣計算直線最近 15 筆，再選出道路最近 6 筆。
- 搜尋序號防止切換國家後，舊的慢速結果覆蓋新地點。
- 德國及其他現有國家補充主要城市；行政區可使用內建座標或背景地理編碼校準。
- 所有頁面、manifest、Service Worker 與快取統一為 `v=113`。

## iPhone Safari 更新

上傳全部檔案後開啟 `deploy-check.html?v=113`，確認顯示 V10.11。若仍顯示舊版，請到 iPhone「設定 → App → Safari → 進階 → 網站資料」刪除該 GitHub Pages 網站資料後重新開啟。
