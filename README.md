# 即時譯 V10.2｜旅外安全助理・Clean Room App

乾淨全重建版，不沿用舊 runtime。

核心功能：
- 雙向文字翻譯、語音輸入、TTS 播放、離線緊急短句
- 國家／城市／地區同步內建，首頁啟動不等待網路
- GPS 或手動位置
- 當地警察／救護／消防電話
- 危機選單即時切換求助句
- 最近醫院／警察局／藥局 Google Maps 導航
- 分享目前位置
- 我的旅行資料卡、敏感資料預設遮蔽
- Open-Meteo 天氣背景更新
- USGS 地震背景更新、與所在地距離計算、綠／橙／紅分級
- GDELT 重大新聞／戰爭／災害背景監測
- Notification 前景／瀏覽器通知
- PWA App Shell、離線核心快取、舊 Cache 自動清除

注意：
- 外部即時服務逾時時，不阻塞 App 基本功能。
- 新聞監測不等同政府官方警報；旅遊警示另提供外交部領事事務局官方入口。
- 靜態 GitHub Pages 無法保證 App 完全關閉後仍有伺服器主動推播；真正背景 Web Push 仍需後端 Push Service。
