# 即時譯 V10.7｜旅外安全助理・區域風險與地圖修正版

V10.7 重點：
- 修正備援地圖：Google Maps + Apple 地圖兩套按鈕
- 備援搜尋改以「設施類型 + 國家 + 城市 + 行政區」搜尋，不再只塞 GPS 座標
- 附近設施仍先用 Overpass 三個端點搜尋，失敗才備援
- 安全頁新增「安全參考 / 可能有危害 / 提高警覺 / 高風險」區域分級
- 當地國家資訊顯示：所在地、警察、救護、消防
- 重大風險在 PWA 主畫面模式且通知權限已允許時，會由 Service Worker 發出通知
- 擴充日本、南韓、中國大陸、泰國、馬來西亞、越南、菲律賓、印尼、美國、澳洲、加拿大與歐洲城市
- 所有新增城市名稱以繁體中文顯示

限制：
- GitHub Pages 是靜態網站。App 完全關閉後要做到真正伺服器主動推播，仍需 Web Push 後端。
- 安全區分級是「事件訊號參考」，不是治安保證。
